Stripe checkout Real card checkout, payment confirmed automatically
Use a restricted key, not your full secret key. In Stripe go to Developers → API keys → Create restricted key, and allow only Checkout Sessions: write and Balance: read. It starts with rk_live_. If it ever leaked, nobody could move your money with it.

In Stripe: Developers → Webhooks → Add endpoint. Send these events: checkout.session.completed, checkout.session.expired, checkout.session.async_payment_succeeded, checkout.session.async_payment_failed. Stripe then shows you the signing secret to paste above.

If a buyer never finishes paying, the hold expires and their stock goes straight back on the shelf. Stripe's own minimum is 30 minutes.
