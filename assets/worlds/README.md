# Illustrated worlds

Original generated scene artwork for the PBM collector storefront. These scenes
are decorative illustrations, separate from the inventory's product photographs.

| Setting | Scene |
| --- | --- |
| crystal | Moonlit Suicune lake and lantern-lit shop |
| halloween | Gengar outside a haunted woodland shop |
| christmas | Suicune in a snowy Pokémon village |
| birthday | Pikachu courtyard celebration |

Full WebP files are 1536×1024; `-mobile.webp` variants are 960×640. Both sizes use
the same composition so responsive image selection does not change the scene.
Keep the subject on the right when replacing artwork: storefront copy overlays
the left side on desktop. The admin theme setting controls the scene on both pages.
